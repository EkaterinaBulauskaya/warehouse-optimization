# abc_xyz

ABC/XYZ-анализ ассортимента: категории по маржинальности (ABC) и по стабильности спроса (XYZ). Итог — матрица категорий по SKU.

Результат сохраняется в файл `out/out_abc_xyz_analysis_results.csv`.

## Входные файлы

Скрипт использует один файл во входной директории `in/`:

- `in/in_for_abc_xyz_analysis.csv` — построчная история по SKU.

Обязательные колонки:

- `Day` — дата продажи/наблюдения (парсится в дату).
- `SKU` — идентификатор товара.
- `Sold` — продажи за строку.
- `Price` — цена продажи.
- `Cost` — себестоимость.
- `Status` — признак наличия (`1` — был в наличии, `0` — не было в наличии).

Примечания:

- Служебные колонки `Unnamed:*` (например после экспорта из pandas) автоматически игнорируются.
- Для участия SKU в расчете нужно минимум 90 дней валидной истории.

## Запуск

```bash
python get_product_abc_xyz_analysis.py
```

## Выходной файл

- `out/out_abc_xyz_analysis_results.csv`

Таблица также выводится в консоль.
